# 🚀 DevOps From First Principles

This repository is a **DevOps + Cloud + System Architecture knowledge base** built from first principles.

> [!TIP]
> ## ⚡ Pareto Learning
> First learn the small set of concepts that explains most real-world infrastructure.  
> Rare commands, edge cases and advanced internals come later.

**Black Box → Why → Mental Model → Architecture → Internals → Hands-on → Active Recall**
